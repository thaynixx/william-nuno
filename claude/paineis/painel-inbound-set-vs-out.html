1.013 MQL enriquecidos e zero SQL. São 37% do MQL dos dois funis combinados. O enriquecimento infla o funil sem trazer resultado no fundo.
Ponto fraco: o tamanho que o Harvest devolve não foi validado contra a realidade. Se estiver errado, o problema é do enriquecimento. Se estiver certo, o problema é a regra de MQL aceitar quem declara 1-10. Zero SQL é compatível com as duas hipóteses.
Método. Signup: janela de 07 a 26 de cada mês, Inbound, definição de enriquecida = declarou 1-10, Autônomo ou nada, e o Harvest devolveu 11 ou mais. Web Request: mês completo, Inbound, definição de enriquecida = passou pelo Harvest (campo Enrich Harvest API Company Size preenchido) e virou MQL por causa do novo tamanho. As janelas são diferentes porque o painel de Signup foi construído primeiro com a janela de 07 a 26; o Web Request usa mês completo. A conclusão é a mesma nos dois recortes.
